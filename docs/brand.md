# brand.md — 톤·용어·카피 규칙

> Design.md가 "보이는 것"(색·글자·간격·컴포넌트)이라면, brand.md는 "읽히는 것"(말투·단어·문장)이에요.
> 색이나 크기 이야기는 여기에 쓰지 않아요.

## 1. 톤

- 해요체 존댓말로 써요. ("~합니다", "~하세요" 명령형보다 "~해요", "~할 수 있어요")
- 한 문장에 정보 하나. 문장은 짧게.
- 고객을 탓하지 않아요. "잘못 입력하셨습니다" 대신 "휴대폰 번호 11자리를 입력해 주세요".
- 과장하지 않아요. "최고의", "파격" 같은 수식어를 쓰지 않아요.

## 2. 용어

| 쓰는 말 | 쓰지 않는 말 |
|---|---|
| 요금제 | 플랜, 상품 |
| 구독 신청 | 가입, 구매, 주문 |
| 월 요금 | 월정액, 이용료 |
| 혜택 | 서비스, 부가혜택 |
| 데이터 무제한 | 무제한 데이터, 데무 |
| 휴대폰 번호 | 핸드폰 번호, 전화번호 |

## 3. 카피 규칙

- 버튼은 동사형으로, 눌렀을 때 일어나는 일을 써요: "구독 신청하기", "신청하기", "자세히", "요금제 더 보기"
- 같은 동작은 끝까지 같은 이름: 버튼이 "신청하기"면 완료 문구도 "신청이 완료됐어요"
- 금액: "월 85,000원" (월을 앞에, 천 단위 쉼표, "원" 붙여 쓰기)
- 데이터: "데이터 110GB", "데이터 무제한"
- 날짜·시간: "10월 13일 14:02"
- 개인정보 표시: 이름은 가운데를 가려요(김*플), 휴대폰 번호는 가운데 4자리를 가려요(010-****-5678)

## 4. 상황별 문구

| 상황 | 문구 |
|---|---|
| 목록이 비었을 때 | 조건에 맞는 요금제가 없어요. 조건을 바꿔 보세요. |
| 불러오는 중 | 요금제를 불러오고 있어요 |
| 불러오기 실패 | 요금제를 불러오지 못했어요. 다시 시도해 주세요. |
| 필수 입력 누락 | 필수 입력 정보예요. |
| 휴대폰 번호 형식 | 휴대폰 번호 11자리를 입력해 주세요. |
| 동의 누락 | 개인정보 수집·이용에 동의해야 신청할 수 있어요. |
| 신청 실패 | 신청하지 못했어요. 잠시 후 다시 시도해 주세요. |
| 신청 완료 | 구독 신청이 완료됐어요 |
| 실습 안내 | 실습용 화면이에요. 실제 이름과 번호는 입력하지 마세요. |
